4-Layer Defense-in-Depth Architecture

Even if the LLM is compromised by untrusted resume text, AWS infrastructure blocks the blast radius
Layer 1 • Input & Output

Amazon Bedrock Guardrails

PROMPT_ATTACK (HIGH) + Denied Topic UnauthorizedOfferOrSalary block direct jailbreaks on input; EMAIL & PHONE PII filters anonymize leaks on output.

Layer 2 • Blast Radius

Scoped IAM Explicit Deny

Execution role grants dynamodb:GetItem only on HireGuard_Candidates and attaches an explicit Deny on HireGuard_Offers, forcing AccessDeniedException.

Layer 3 • Deterministic Gate

Lambda Policy Enforcement

HireGuardTools hardcodes int(rubric_score) < 75 in Python—catching polite social-engineering requests that intentionally sound harmless to Layer 1.

Layer 4 • Human-in-the-Loop

Confirmation Gate + Identity

Irreversible rejections pause with RETURN_CONTROL for recruiter sign-off. Model API keys live in AWS AgentCore Identity—zero hardcoded secrets.
